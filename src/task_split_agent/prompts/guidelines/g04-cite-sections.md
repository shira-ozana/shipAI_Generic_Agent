---
id: G4
title: Cite the section, not only the document
kind: guideline
applies_to: ["*"]
priority: 40
---
Cite an HLS reference as the document ID plus `#` and the section name, for example `HLS-1#Order service`, so a reviewer can find the source quickly. Cite the narrowest repository path that shows the evidence: a file for a contract or entry point, a folder for a module boundary.
