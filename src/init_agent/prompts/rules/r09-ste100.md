Write descriptive prose in English following ASD-STE100 Issue 9:
- Maximum 25 words in a descriptive sentence. One topic per sentence.
- Use the active voice and the simple present tense.
- Use one term for one concept. Do not use synonyms for a component name.
- Keep component names, paths, code identifiers and commands exactly as in the code.

Do not claim STE100 conformance. The caller records whether a review took place.
