Use this to add diagrams to the HLD, in Mermaid fenced code blocks.

- Overall HLD: one component diagram (`flowchart LR`) showing the components
  and how they connect, and one sequence diagram (`sequenceDiagram`) for the
  main flow of the feature.
- Component HLD: add a sequence or flowchart only when the internal flow is
  not obvious from text.
- Keep diagrams small and readable: names must match the component names used
  in the text. Quote labels that contain special characters.
